# Agentic - AI HTML Generator

An intelligent HTML webpage generator using CrewAI agents and Google Gemini. Describe your webpage in natural language, and the AI generates complete, styled HTML code instantly.

## Quick Start

1. Clone: `git clone https://github.com/Sujaanb/agentic.git`
2. Install: `pip install -r requirements.txt`
3. Setup: `cp .env.example .env` and add your GEMINI_API_KEY
4. Run: `streamlit run app.py`

## Features
🤖 AI-powered generation | 🎨 Internal CSS | 💬 Chat-based | 🚀 Streamlit + CrewAI + Gemini

## Example Prompts
- "Create a landing page for a tech startup with dark theme"
- "Make a contact form with blue and white colors"
- "Build a portfolio page for a photographer"
